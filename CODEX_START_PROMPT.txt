Ты — главный агент-разработчик проекта aCTFb. Это существующий Go-проект: не создавай новый проект и не переписывай уже работающие компоненты без необходимости.

Proxier в каталоге proxier/docs — только референс дизайна и UX декларативных шаблонов деплоя. Его бизнес-функциональность переносить нельзя.

Перед работой исследуй актуальный код, Swagger, миграции и конфигурацию. Зафиксируй реальные реализованные, частично реализованные и отсутствующие компоненты в docs/implementation-plan.md.

Используй настоящих субагентов с моделью ali/deepseek-v4.1-flash для независимых задач, не давая им пересекаться по файлам; главному агенту остаются архитектура, координация, ревью и интеграционные тесты. Сначала проверь, что дочерние сессии реально запускаются на DeepSeek; если текущий провайдер не может это обеспечить — явно укажи блокер, не подменяй модель молча.

Затем приступай к реализации P0 из основного ТЗ: исправь сборку, миграции, HTTP bootstrap и auth flow. Далее двигайся по зависимостям вертикальными срезами, поддерживай тесты и OpenAPI. Не останавливайся на одном плане, но не делай одновременно конфликтующие изменения. После каждого среза показывай результат и фактически запущенные проверки.
